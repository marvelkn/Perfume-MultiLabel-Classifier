# Pemeriksaan label aroma

Folder ini berisi hasil pemeriksaan label, bukan data training baru.

Mulai dari **LABEL_AUDIT_FINDINGS.md** untuk penjelasan, lalu **summary.json** untuk hitungan. **unmatched_terms.csv** berisi istilah yang tidak terpetakan; **taxonomy_selection.csv** menjelaskan label yang masuk atau tidak masuk target model.

Isinya dipertahankan sesuai audit asal. Nama folder lama hasil_audit_label sekarang menjadi 06_Audit_Label. Lihat ../PETA_FOLDER.json untuk pemetaan lengkap.
